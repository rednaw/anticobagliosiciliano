# Site copy

This file is there to make it easier to translate the site into more than one language.

Each row is one string; Italian and English have their own columns. Open it in FileMaker, Excel, or any other CSV app, edit, and send it back: I will put the changes on the site. You don’t have to do it all at once — send the file whenever you like; importing it is little work for me, and we can do it as many times as is needed.

Leave the structure of the file as it is; only change the texts in the Italian and English columns.

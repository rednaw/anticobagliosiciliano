# Testi del sito

Questo file serve a rendere più semplice la traduzione del sito in più lingue.

Ogni riga è un testo; italiano e inglese hanno ciascuno una colonna. Potete aprirlo in FileMaker, Excel o un altro programma che legge i CSV, modificare i testi, e rimandarlo qui: le inserisco io nel sito. Non serve farlo tutto in una volta: mandate il file quando volete, per me importarlo è poco lavoro e possiamo farlo tutte le volte che serve.

Lasciate la struttura del file com'è; cambiate solo i testi nelle colonne italiano e inglese.
